# Duka Scraper documentation

Duka Scraper is a distributed crawler and analytics pipeline for Amharic and English web content. The implementation in this repository currently runs through Kafka, PostgreSQL, MinIO, Elasticsearch, ClickHouse, and Ollama-backed intelligence classification.
